# CLAUDE.md

Site **Altus Performance** (GitHub Pages, https://altus-golf.github.io/) : défis de putting, classements et suivi des joueurs du groupe Altus. Tout en **français**, code simple et commenté en français (l'utilisateur débute en code). Projet séparé de l'appli d'entraînement perso (dépôt `mathdebournet-ui/golf`) : ne jamais faire apparaître le nom du compte perso (mathdebournet-ui) ni d'adresse e-mail sur ce site.

## Règles

- Ne jamais pousser sans accord explicite de l'utilisateur. Le site est publié depuis `main`.
- **À chaque modif publiée, augmenter `?v=N` dans index.html** (style.css et tous les .js) : sinon les téléphones gardent l'ancienne version en cache.
- Tout accès `localStorage` passe par `lireStockage` / `ecrireStockage` (base.js, try/catch).
- Données reçues en ligne = non fiables : toujours normalisées (`normaliserBilan`, `normaliserDefi`, `normaliserConsignes`) et échappées (`echapper`).
- Adresses des coachs : jamais dans le dépôt (placeholders `ADRESSE_COACH_n` dans `outils/regles-firestore.txt`).
- **Distances : jusqu'à 10 pieds en PIEDS, au-delà en MÈTRES ; les zones (1, 2, 4 pieds…) toujours en pieds** (choix de l'utilisateur, 19/11/2026) ; exceptions : **Lowry Putt et Start Line tout en pieds** (`TOUT_EN_PIEDS`), **9 Putt Circle affiché 4, 5, 6 m** (`METRES_9_PUTT`) : `distanceAltus` dans exos-altus.js (texte des puces `p.texte` + `config.libelle`, sans toucher aux distances `d`), `remplacerTextes` pour les zones ; barème du Pelz en pieds (< 3 / 3 à 6 / > 6).
- Exercices : uniquement des exos de PERFORMANCE (jeu noté). Ne jamais mentionner le « SG » du PDF Trèfle.
- `exos-points.js` est une **copie telle quelle** de l'appli golf (jeux interactifs) : ne pas l'éditer, les réglages Altus sont dans `exos-altus.js`. Une amélioration d'un côté ne passe pas toute seule de l'autre : recopier si l'utilisateur le demande.
- **Long jeu : 6 Test Center Trackman** (`TESTS_CENTER`, exos-altus.js, demandés le 19/11/2026 : Fix Wedge 60-90 m, Random 60-90 m, Fix Wedge 100-150 m, Random 100-150 m, Random 150-180 m, Driver) : fiches `saisie: true` / `longJeu: true`, pas de jeu, le joueur tape le score Trackman (`zoneSaisie` / `enregistrerSaisie`, /100, plus haut = mieux, une décimale, confirmé par l’utilisateur) ; onglet Exos : section « Long jeu » à part.
- **Programme Altus = les 11 exos du classeur Google « ALTUS Saisie Training Petit Jeu/Putting » (onglet Exercices)**, règles recopiées telles quelles. Ne pas publier les prénoms ni les scores des joueurs de ce classeur.

## Fichiers (scripts classiques, noms globaux partagés)

Ordre : `base.js` → `scores.js` → `exos-points.js` → `exos-altus.js` → `classeur.js` → `match.js` → `app.js`.
- **match.js** (20/11/2026) : ⚔️ match play entre joueurs. Un des deux joueurs entre le RÉSULTAT (adversaire choisi parmi les prénoms du groupe, gagné / égalité / perdu, score 1 up…10&8 ou AS, date, parcours) ; classement de l'année dans l'onglet ⚔️ Matchs (`vueMatchs` → `blocMatchPlay` : V / N / D, victoire 1 pt, nul ½), « Mes matchs entrés » pour effacer une erreur. En ligne `groupes/ALTUS/matchs/<id>` {auteur, j1 (= l'auteur), j2, gagnant 0/1/2, score, date, parcours, cree} (`ajouterMatch` / `effacerMatch` / lecture dans `lireGroupe`, base.js ; si les règles ne sont pas recollées, la lecture échoue sans casser le reste). Joueurs reconnus par prénom (`slugPrenom`).
- **classeur.js** : import de l'historique du classeur (onglet Saisie : fichier Excel .xlsx choisi directement — lu avec SheetJS 0.18.5 chargé depuis cdnjs seulement à ce moment, `texteDuFichierExcel` —, colonnes A-E collées ou CSV ; avec le .xlsx, les onglets des joueurs sont lus aussi : lignes de séance à partir de la ligne 15, ligne 3 = exo, ligne 4 = situation, doublons avec Saisie ignorés, ligne sans date signalée « ⚠ sans date » et ignorée ; un joueur avec un onglet mais sans score devient un bilan importé vide pour apparaître dans les listes, sauf s’il est déjà inscrit sur le site) depuis l'espace coachs → un bilan `classeur-<prénom>` par joueur (`source: "classeur"`, écrit par un coach via `importerBilans`, base.js ; Pelz complet recalculé par semaine). **Les données ne vont jamais dans le dépôt** (public). Un joueur qui se connecte avec le même prénom peut « récupérer » cet historique (copié dans ses scores, `moi().repris` → champ `repris` de son bilan) ; un bilan importé repris est masqué des classements et de l'espace coachs ; les bilans importés ne comptent pas pour le flemmard.
- **exos-altus.js** : `FICHES_ALTUS` (11 exos à jouer, `regles` = texte du classeur), `ITEMS_ALTUS` (scores classés : Pelz A…I /40 + `pelz-total` /360 de la semaine, Start Line 5/10/20 ft /10, Trèfle = meilleure série /16, Snail = 8 putts de 3 à 10 ft dans l’ordre, un par puce (pas de montante / descendante), score = rentrés /8, Leap Frog = série…), `itemDe`, `ficheDe`. Réglages des jeux SANS toucher exos-points.js : exos hors programme supprimés de `EXOS_POINTS`, Start Line sans version courte, Snail noté ; `terminerExo` enveloppée (`scoreAltus(tour)` lu avant la fin, `scoreAltusEnAttente` utilisé par `enregistrerScore`, message de fin réécrit). **Test de Pelz** interactif : 10 balles par situation, barème 4/2/1/0 (`PELZ_BAREME`), tour en cours `altus-scores-v1:pelzEnCours`, « Pelz de la semaine » = dernier score de chaque situation depuis lundi, total enregistré (un par semaine) quand les 9 sont faites.
- **base.js** : stockage, dates (`lundiDe`), base partagée. `CONFIG_FIREBASE` = projet Firebase **altus-golf** (branché le 19/11/2026 ; mettre `null` = mode démo : 6 joueurs fictifs + défi Trèfle, fausse base dans `altus-v1:demo`). `hist` part en ligne en `[{d, v}]` (Firestore refuse les tableaux de tableaux) et revient en `[[d, v]]` par `normaliserBilan`. **Tout le monde se connecte avec Google** (choix de l'utilisateur, 19/11/2026 ; plus de connexion anonyme) : `connecterGoogle` (fenêtre ouverte sans attente avant, sinon le téléphone la bloque), `utilisateurGoogle`, `suivreConnexion` (redessine à chaque connexion ; autre compte = prénom redemandé), `deconnecter`. Coach = compte dont l'adresse est dans les règles : `verifierCoach` essaie d'ouvrir le groupe (réussi = coach, `estCoachConfirme`). Seul le prénom est affiché, jamais l'adresse. En ligne : `groupes/<CODE>` (créé par un coach), `bilans/<uid>` (un document par joueur, écrit par lui seul), `reglages/defi` {fiches (≤ 40 = sans vraie limite, plusieurs défis par semaine depuis le 19/11/2026), fiche (= le 1er, pour les anciennes versions), lundi, message} (`normaliserDefi` accepte encore l’ancien {fiche}), `consignes/<uid>` {exos, message, faits}. **Un seul groupe, sans code** (`CODE_GROUPE = "ALTUS"`, choix de l'utilisateur 19/11/2026) : ouvert par `verifierCoach()` quand un coach ouvre l'espace coachs. Joueur = compte Google + prénom **choisi dans la liste des prénoms du groupe** (accueil, choix de l’utilisateur 19/11/2026 : `prenomsDuGroupe` base.js, `vueAccueil` / `entrerAvecPrenom` app.js ; un historique importé du même prénom est récupéré tout de suite ; « Je ne suis pas dans la liste » = prénom tapé, pré-rempli avec le prénom Google) (`moi()` = {code: CODE_GROUPE, prenom, uid}) .
- **scores.js** : recrée pour Altus les fonctions que exos-points.js attend (`enregistrerScore`, `lireScores`, `texteScore`, `UNITES_SCORE`…). Scores dans `altus-scores-v1:scores` = {fiche: [{t, d, v}]} (jamais purgés).
- **app.js** : vues Séance (⭐ exos du coach, puis 🎯 défis de la semaine, toujours jouables : `defisDeLaSemaine`), 🏆 Classements (un classement par défi de la semaine, calculé depuis `hist` par `meilleurCetteSemaine`, 🦥 flemmard = moins d'exos joués depuis lundi, par exo : ⭐ record absolu de l'année + 🏆 top 3 à la moyenne de l'année, 3 scores minimum), 📈 Moi (records + courbes + moyenne des 30 derniers jours `moyenne30`, rangés en 3 catégories repliables `CATEGORIES_PROGRES` : ⛳ Putting, 🏌️ Chipping (Pelz), 📡 Test Center ; dans l’ordre de `ITEMS_ALTUS`), 📚 Exos, 🧑‍🏫 Espace coachs (groupe, défis, exos donnés à un joueur, progrès, 🗑 retirer un joueur = `supprimerJoueur` dans base.js : bilan + consignes ; 📊 rapport Excel = `blocRapportExcel` / `telechargerRapport` (classeur.js, SheetJS, fabriqué chez le coach : une feuille par joueur avec TOUS les exos, même sans score, rangés Putting / Chipping / Test Center) ; 🎯 putts rentrés par distance = `blocDistances` (« tous » = seulement les exos où réussir = rentrer, `motReussi(exo) === "rentrés"` : Trèfle, Snail ; les exos à zone se choisissent un par un), distances regroupées par leur texte affiché `config.libelle`, triées par `config.piedsDe` (exos-altus.js)). Après chaque exo : `apresUnExo` → exo du coach coché, `calculerBilan` → `publierBilan`.
- Bilan d'un joueur = {uid, prenom, maj, annee, exos {fiche: {n, moy, record, recordD}} (année en cours), hist {fiche: [[d, v]]} (30 derniers), semaine {lundi, n}, defi {lundi, fiche, meilleur} (ancien), dist {exo: {distance: [réussis, tentés]}} (exos interactifs, année en cours, `distancesDeLAnnee` ; champ ajouté aux règles le 19/11/2026 : si les règles ne sont pas recollées, `publierBilan` renvoie le bilan sans `dist`)}.
