# CLAUDE.md

Site **Altus Performance** (GitHub Pages, https://altus-golf.github.io/) : défis de putting, classements et suivi des joueurs du groupe Altus. Tout en **français**, code simple et commenté en français (l'utilisateur débute en code). Projet séparé de l'appli d'entraînement perso (dépôt `mathdebournet-ui/golf`) : ne jamais faire apparaître le nom du compte perso (mathdebournet-ui) ni d'adresse e-mail sur ce site.

## Règles

- Ne jamais pousser sans accord explicite de l'utilisateur. Le site est publié depuis `main`.
- **À chaque modif publiée, augmenter `?v=N` dans index.html** (style.css et tous les .js) : sinon les téléphones gardent l'ancienne version en cache.
- Tout accès `localStorage` passe par `lireStockage` / `ecrireStockage` (stockage.js, chargé dans le `<head>` ; avant le 21/11/2026 dans base.js ; try/catch ; si le navigateur refuse d’enregistrer — navigation privée, navigateur d’appli — tout est gardé en mémoire le temps de la visite, `memoireSecours`, et le bandeau `#bandeau-stockage` prévient le joueur).
- **Jamais de `alert()` / `confirm()` natifs** (bloqués sans message dans les navigateurs d'applis) : `afficherMessage` / `demanderConfirmation` (base.js, fenêtre dans la page ; `window.alert` est remplacé, et `abandonnerExo` de exos-points.js est enveloppé dans exos-altus.js).
- **Sauvegarde en ligne des scores** (20/11/2026) : à CHAQUE `chargerGroupe` (ouverture, retour sur l’appli, après un exo), `restaurerDepuisEnLigne` (app.js) remet dans le téléphone ce qui est en ligne (`groupes/ALTUS/sauvegardes/<uid>` = tous les scores, `repris`, techniques, `effaces`, `tours` des exos interactifs = détail par distance, sinon un autre téléphone renvoyait un bilan sans `dist` ; sinon les 30 derniers de mon bilan ; les coachs peuvent LIRE les sauvegardes → rapport Excel avec TOUS les scores, `lireSauvegardesCoach`, repli sur les 30 du bilan si pas encore de sauvegarde) ; `publierMonBilan` (bilan + sauvegarde) ne publie RIEN tant que ce n'est pas fait (`sauvegardeVerifiee`) — sinon un téléphone vide écrasait le bilan en ligne. Ne jamais appeler `publierBilan(calculerBilan())` directement. **Effacer un score tapé par erreur = COACHS SEULEMENT** (anti-triche, choix de l'utilisateur 20/11/2026) : espace coachs > progrès du joueur > « ✏️ Effacer un score » (`blocCorriger`, action `coach-effacer-score`). Joueur du site : effacé TOUT DE SUITE dans sa sauvegarde (`ecrireSauvegardeDe`) et son bilan recalculé avec tous ses scores (`importerBilans` ; règles : un coach peut écrire tous les bilans et sauvegardes), + demande dans `consignes.aEffacer` [{id, d, v, cle, t}] pour ses téléphones, appliquée par `appliquerEffacementsCoach` (app.js) à son prochain chargement ; `restaurerDepuisEnLigne` enlève aussi du téléphone les scores effacés : `effaces` = clés « exo|t » (`cleEfface` / `estEfface`, base.js ; JAMAIS le `t` seul : les scores du classeur ont tous t = midi du jour → un effacement en emportait d'autres, bug du 20/11/2026 ; anciens nombres seuls ignorés s'ils tombent sur une seconde ronde), et refusionne l'historique du classeur repris (réparation) (cle gardée dans `altus-scores-v1:effacesCoach` + sauvegarde, `t` du score dans `effaces` pour qu'il ne revienne pas) ; historique importé 📄 : le coach réécrit directement le bilan. **➕ Ajouter un score** (coachs seulement, 20/11/2026, `blocAjouterScore` / action `coach-ajouter-score`, app.js) : exo + date + score ; joueur du site = ajouté dans sa sauvegarde (créée à partir de son bilan s'il n'en a pas encore ; jamais si la lecture a échoué, `lireSauvegardesCoach(uids, erreurs)`) avec t = maintenant (jamais pris pour un ancien Trèfle en série ni un score effacé) + bilan : hist recalculé, stats de l'année = celles du bilan + ce score ; ses téléphones le récupèrent à l'ouverture ; 📄 = bilan réécrit (pas de Trèfle : il serait effacé par le ménage).
- Données reçues en ligne = non fiables : toujours normalisées (`normaliserBilan`, `normaliserDefi`, `normaliserConsignes`) et échappées (`echapper`).
- Adresses des coachs : jamais dans le dépôt (placeholders `ADRESSE_COACH_n` dans `outils/regles-firestore.txt`).
- **Distances : jusqu'à 10 pieds en PIEDS, au-delà en MÈTRES ; les zones (1, 2, 4 pieds…) toujours en pieds** (choix de l'utilisateur, 19/11/2026) ; exceptions : **Lowry Putt et Start Line tout en pieds** (`TOUT_EN_PIEDS`), **9 Putt Circle affiché 4, 5, 6 m** (`METRES_9_PUTT`) : `distanceAltus` dans exos-altus.js (texte des puces `p.texte` + `config.libelle`, sans toucher aux distances `d`), `remplacerTextes` pour les zones ; barème du Pelz en pieds (< 3 / 3 à 6 / > 6).
- Exercices : uniquement des exos de PERFORMANCE (jeu noté), **sauf les 4 exos de technique** demandés par le coach le 20/11/2026 (`TECHNIQUES`, exos-altus.js : grand jeu, putting, chipping, wedging) : exos PERSONNELS, seulement quand un coach les donne à un joueur (pas dans l'onglet Exos, pas de score ni de classement) ; le coach fixe une durée OU un nombre de balles (`consignes.reglages`), le joueur écrit son ressenti à la fin (`zoneTechnique` / `finirTechnique` → `consignes.ressentis` ; gardé dans `altus-scores-v1:consignesEnAttente` et renvoyé par `envoyerTechniquesEnAttente` à chaque `chargerGroupe` tant que l’envoi échoue ; ≤ 30, les plus récents d'abord ; règles : le joueur peut modifier `faits` et `ressentis`) ; le coach voit les ressentis dans l'espace coachs et le rapport Excel. Ne jamais mentionner le « SG » du PDF Trèfle.
- `exos-points.js` est une **copie telle quelle** de l'appli golf (jeux interactifs) : ne pas l'éditer, les réglages Altus sont dans `exos-altus.js`. Une amélioration d'un côté ne passe pas toute seule de l'autre : recopier si l'utilisateur le demande.
- **Long jeu : 6 Test Center Trackman** (`TESTS_CENTER`, exos-altus.js, demandés le 19/11/2026 : Fix Wedge 60-90 m, Random 60-90 m, Fix Wedge 100-150 m (filles 90-130 m), Random 100-150 m (filles 90-130 m), Random 150-180 m, Driver) : fiches `saisie: true` / `longJeu: true`, pas de jeu, le joueur tape le score Trackman (`zoneSaisie` / `enregistrerSaisie`, /100, plus haut = mieux, une décimale, confirmé par l’utilisateur) ; onglet Exos : section « Long jeu » à part.
- **Programme Altus = les 11 exos du classeur Google « ALTUS Saisie Training Petit Jeu/Putting » (onglet Exercices)**, règles recopiées telles quelles. Ne pas publier les prénoms ni les scores des joueurs de ce classeur.
